# 🚀 DevMarket / Nodera

Современный фуллстек-маркетплейс и портфолио для продажи веб-разработки, скриптов, ботов и готовых решений. Проект написан с использованием передовых веб-технологий и оформлен в строгом тёмном стиле (в духе GitHub и WebStorm).

---

## 🛠️ Стек технологий

- **Фреймворк:** [Next.js 14.x](https://nextjs.org/) (App Router, Server & Client Components)
- **База данных и ORM:** [Prisma v5](https://www.prisma.io/) + SQLite (`dev.db`)
- **Стилизация:** Кастомная CSS-архитектура (тёмная тема на базе Tailwind-концептов)
- **Язык:** JavaScript (ES6+)

---

## ✨ Основной функционал

- **Динамический каталог и фильтры:** Быстрый просмотр скриптов и инструментов с фильтрацией по категориям (Python, Frontend, DevOps и т.д.).
- **Подписка на рассылку:** Интегрированная форма ввода email в шапке сайта, подключенная напрямую к базе данных через REST API.
- **Оформление заказов:** Полноценная система фиксации покупок, привязанная к почте пользователя и ID товара.
- **Адаптивный интерфейс:** Аккуратный дизайн с плавными ховерами, современными плашками статусов и интерактивными элементами.
